# WIC 공통 고객 출력·추천 규칙

## 적용 범위
모든 이메일 수집 대화창, 고객 추천 대화창, 안내서 생성 작업, 관련 자동화 도구에 공통 적용한다.

## 고객번호 필수 규칙
- 모든 고객 인력 출력에는 고객번호를 반드시 함께 표시한다.
- 중간 단계에서 고객번호가 누락되었더라도 최종 출력 전에 반드시 복원·확인한다.
- 고객번호 없이 고객 정보를 출력하거나 다음 단계로 전달하지 않는다.
- 고객번호는 고객 DB, 추천자료 표, 중간 안내서 작업 대상, 최종 안내서 작업 대상, 발송이력에서 동일한 식별자로 유지한다.
- 이름·이메일이 같아도 고객번호 기준으로 중복 여부를 다시 확인한다.

## 추천 보고서 발행사 다양성 규칙
- 추천 자료는 특정 2~3개 발행사에 편중하지 않는다.
- 월드산업정보센터가 실제 거래하는 전체 발행사 풀을 대상으로 후보를 찾는다.
- 고객의 기관 산업, 부서 기능, 실제 담당업무, 연구·사업 방향과 직접 맞는 자료만 남긴다.
- 최근 발행 자료를 우선한다.
- 같은 고객에게 3종 추천 시 가능한 범위에서 발행사를 분산한다.
- 실제 거래 발행사 여부가 확인되지 않으면 추천 후보에서 제외하거나 HOLD 처리한다.

## 실제 보고서 데이터 검증 규칙
- 임의 보고서명, 임의 링크, 임의 목차, 임의 발행정보 생성 금지.
- 실제 발행사 페이지에서 확인되는 자료만 사용한다.
- 출력 제목과 링크 페이지의 실제 제목이 일치해야 한다.
- 발행사, 발행일, 페이지, 가격, 링크, 목차는 확인 가능한 값만 사용한다.
- 확인되지 않는 값은 추정하지 않고 확인 필요/HOLD로 처리한다.
- 링크 오류, 제목 불일치, 리디렉션으로 다른 자료가 열리는 경우 폐기한다.

## 중복 방지 규칙
- 고객번호 + 이름 + 이메일을 기본 중복키로 사용한다.
- 이미 처리·발송한 고객은 발송이력을 먼저 확인한다.
- 같은 고객에게 같은 보고서를 다시 추천하거나 발송하지 않는다.
- 분야별 대화창이 달라도 공통 중복기록을 기준으로 차단한다.

## 안내서 양식 규칙
- 사용자가 제공한 월드산업정보센터 실제 안내서 원본 양식을 기준으로 한다.
- 새 안내서 양식을 임의로 재구성하지 않는다.
- 원본 구조·표·테두리·글꼴·배치를 유지하고 필요한 데이터 슬롯만 교체한다.

## 운영 원칙
이 문서는 공통 기준 파일이며, 이후 규칙 보완 시 새 문서를 덧대지 말고 가능한 한 이 파일을 갱신한다.
