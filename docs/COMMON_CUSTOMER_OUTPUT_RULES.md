# LEGACY — 고객 안내 규칙 이전 완료

이 파일은 더 이상 고객 안내 규칙의 기준본이 아니다.

모든 고객 안내·추천자료·고객 컨택·메일 문안·중간안내서·최종안내서 규칙은 아래 단일 공통마스터로 이전·통합되었다.

- 기준 파일: `docs/UNIFIED_CUSTOMER_GUIDANCE_RULES.md`

운영 규칙:
- 이 파일에 새 규칙을 추가하지 않는다.
- 이 파일과 통합마스터가 충돌하면 통합마스터를 적용한다.
- 과거 내용 확인이 필요한 경우 Git 이력으로만 조회한다.
- 모든 분야별 고객 안내 대화창과 관련 도구는 `UNIFIED_CUSTOMER_GUIDANCE_RULES.md`만 Source of Truth로 사용한다.
