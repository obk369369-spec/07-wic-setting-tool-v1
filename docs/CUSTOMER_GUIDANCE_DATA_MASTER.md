# 42번 고객 안내 — 분야별 고객 데이터 통합 마스터

> 기준: 2026-08-18 현재 사용자 제공 41-1/41-8/41-13/41-14/41-15 고객 안내 기록 및 이전 동일 사본 대조.

## 운영 원칙
- 기존에 표시된 고객 고유번호/등록번호는 변경·재사용하지 않는다.
- 동일 고객은 이메일 우선, 다음으로 기관+이름을 기준으로 중복 제거한다.
- 원문에 없는 필드는 추정하지 않고 공란으로 둔다.
- 번호가 없던 신규 통합 고객은 해당 분야 안에서 원문 등장 순서대로 번호를 부여한다.
- 방산 첨부기록에는 채워진 고객 인력 데이터가 없어 고객 행을 생성하지 않았다.
- 38번 고객 매일 장부 안내 TXT는 운영 설명/대화기록이며 실제 XLS 고객 행이 포함되지 않아 이 마스터에 신규 고객으로 병합하지 않았다.
