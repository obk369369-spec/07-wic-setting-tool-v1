## 33. 상태보고+안내서 단일응답 잠금 — 2026-08-21
- 사용자가 고객 안내서 출력 또는 재출력을 지시하면, 확인·검증·GitHub 규칙 적용 과정의 중간 설명을 여러 메시지로 나누지 않는다.
- 도구 실행에 필요한 과정은 내부에서 연속 수행하고, 사용자에게는 작업이 끝난 같은 응답에서 `최소 상태보고 1회 → 즉시 안내서 전체`를 연속 출력한다.
- `확인하겠습니다`, `출력하겠습니다`, `다음 답변에서 출력하겠습니다`처럼 실제 안내서 없이 예고만 하는 응답은 FAIL이다.
- 중앙마스터 업데이트와 안내서 재출력을 함께 지시받은 경우에도 `업데이트 실제 실행 → 원격 read-back 검증 → 최소 완료보고 → 같은 흐름에서 안내서 출력`으로 처리한다.
- 단, 3종·목차·상세페이지 검증 조건이 충족되지 않으면 억지 안내서를 출력하지 않고 같은 응답에서 HOLD 사유만 짧게 보고한다.
