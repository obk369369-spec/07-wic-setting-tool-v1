# WIC 고객 안내 대화창 통합 공통 규칙

## 0. 목적
분야별 고객 안내 대화창의 규칙을 하나로 통합해, 이후에는 하나의 고객 안내 대화창에서 분야 구분 없이 같은 기준으로 작업한다. 과거 대화기록 데이터 자체는 이 문서에 중복 저장하지 않고 사용자가 별도로 보관·전달한다.

## 1. 입력 범위
- 검증 완료된 고객 인력 정보만 사용한다.
- 고객번호를 반드시 포함한다.
- 기본 필드: 고객번호 / 기관 / 부서 / 이름 / 직책 / 담당업무 / 연구·사업 키워드 / 이메일 / 전화 / 추가 메모.
- 인력 정보가 이미 검증 완료 상태라면 고객 안내 창에서 다시 인력 탐색·이메일 추정·이름 수정·연락처 추정을 하지 않는다.

## 2. 고객번호·중복 관리
- 고객번호는 모든 출력에 반드시 표시한다.
- 고객번호가 중간 단계에서 빠졌더라도 출력 전에 복원한다.
- 고객번호 + 이름 + 이메일을 기본 중복키로 사용한다.
- 이미 추천·안내·발송한 고객은 이력을 확인해 중복 안내를 차단한다.
- 같은 고객에게 같은 보고서를 다시 추천하지 않는다.

## 3. 고객 매칭 우선순위
추천자료는 다음 순서로 판단한다.
1. 기관의 실제 산업·사업 맥락
2. 부서 기능
3. 담당업무
4. 연구·사업 키워드
5. 최근 연구개발·사업 방향이 확인된 경우 그 방향

- 부서명만 보고 고객을 제외하거나 엉뚱한 일반 보고서를 추천하지 않는다.
- 홍보·대외협력·준법 등 비기술 부서라도 기관 자체가 방산·항공·자동차 등 특정 산업의 핵심 기관이면 기관 산업 맥락을 함께 반영한다.
- 반대로 부서명 단어만 보고 Corporate Training, Project Management Software 등 직접 관련 없는 자료를 연결하지 않는다.

## 4. 추천자료 3종 구조
각 고객 인력당 3개로 고정한다.
1. 핵심 맞춤 자료: 담당업무·연구방향에 직접 연결
2. 유사 확장 자료: 같은 산업/기술 축에서 한 단계 확장
3. 안전 공통 자료: 기관 산업 맥락과 직접 관련성이 높은 범용 자료

- 3개가 모두 약하면 억지로 채우지 않고 HOLD한다.
- 동일한 3개 세트를 여러 고객에게 반복하지 않는다.

## 5. 거래 발행사 기준
- 월드산업정보센터가 실제 거래하는 전체 발행사 풀을 대상으로 후보를 찾는다.
- 특정 2~3개 발행사에 편중하지 않는다.
- 같은 고객의 3개 추천자료는 가능한 범위에서 발행사를 분산한다.
- Research and Markets 같은 단순 유통 사이트는 발행사로 취급하지 않는다.
- 거래 발행사 여부가 불분명한 경우 HOLD한다.
- 외부 발행사를 임의로 섞지 않는다.

## 6. 보고서 실데이터 검증
다음 조건을 모두 통과해야 추천자료로 출력한다.
- 실제 발행사 상세페이지 존재
- 보고서 제목과 링크 페이지 제목 일치
- 링크 정상 작동
- 발행사 확인
- 발행일 확인 가능한 범위 내 표시
- 페이지 수 확인 가능한 범위 내 표시
- 가격 확인 가능한 범위 내 표시
- 목차 또는 개요가 필요한 작업이면 실제 페이지 기준으로 확인

금지:
- 임의 제목 생성
- 임의 링크 생성
- 임의 가격·발행일·페이지·목차 생성
- 검색결과 제목만 보고 상세페이지 검증 없이 출력
- 제목과 링크가 다른 보고서를 같은 자료처럼 표시

확인되지 않는 값은 추정하지 않고 `확인 필요` 또는 HOLD로 둔다.

## 7. 최신성 기준
- 고객과 직접 맞는 자료 중 최근 발행 자료를 우선한다.
- 최신 자료라는 이유만으로 고객 업무와 약한 자료를 선택하지 않는다.
- 직접성 > 최신성 > 발행사 분산 순서로 최종 판단한다.

## 8. 기본 출력 형식
고객 1명 단위로 세로 배치한다. 가로로 긴 통합표를 만들지 않는다.

### 고객 정보 표
고객번호 / 기관 / 부서 / 이름 / 직책 / 담당업무 / 이메일 / 전화 / 검증결과

### 바로 아래 추천자료 표
추천순위 / 제목 / 발행사 / 링크 / 추천 근거 키워드

- 인력 바로 아래 추천자료를 배치한다.
- 고객 정보와 추천자료를 하나의 긴 가로표로 합치지 않는다.
- 가로 스크롤이 생기지 않게 한다.

## 9. 메일 제목·첫 문장·안내문 생성 규칙
필요한 작업에서만 각 고객별로 생성한다.
- 메일 제목 후보 3개
- 첫 문장 후보 3개
- 추천자료 3개
- 필요 시 전화 멘트 / 메일 문장 / 추천 이유 / 다음 액션

반복 방지:
- 같은 제목 반복 금지
- 같은 첫 문장 반복 금지
- 같은 기관 연속 발송 회피
- 같은 도메인·부서 몰림 회피
- 같은 추천자료 조합 반복 회피

## 10. 안내서 관련 규칙
- 사용자가 제공한 월드산업정보센터 실제 안내서 원본을 기준으로 한다.
- 새 양식을 임의로 재구성하지 않는다.
- 안내서 자동 생성이 불안정한 경우 억지로 파일을 만들지 않고, 안내서에 넣을 검증된 데이터만 출력할 수 있다.
- 중간안내서와 최종안내서 세부 규칙은 `COMMON_CUSTOMER_OUTPUT_RULES.md`를 함께 적용한다.

## 11. 중간안내서/최종안내서 연계
- 중간안내서: 목차 대신 발행사 공식 페이지에서 실제 확인되는 공개 콘텐츠를 사용한다.
- 최종안내서: 하단에 실제 검증된 목차를 사용한다.
- 최종 목차는 상위 → 하위 → 하하위 순으로 오른쪽 들여쓰기를 증가시킨다.
- 사용자가 안내서 파일 생성보다 데이터 제공을 요청하면 제목/한글제목/발행사/페이지/가격/발행일/공급가격/링크/중간 콘텐츠 또는 목차 데이터를 분리해 출력한다.

## 12. 금지사항
- 고객 인력 재탐색
- 이메일 주소 추정
- 검증 완료 고객 정보 임의 수정
- 발행사 2~3곳에만 편중
- 고객 연구·사업과 무관한 키워드 연결
- 링크 없는 자료 추천
- 제목-링크 불일치
- 이미 처리한 고객 중복 출력
- 같은 고객에게 같은 보고서 재추천
- 사용자에게 거래 발행사 목록을 매번 다시 요구
- 사용자가 다시 수동 검증해야 쓸 수 있는 결과를 PASS로 표시

## 13. PASS 조건
- 고객번호 존재
- 고객 중복 없음
- 1명당 추천자료 3개 또는 부족 시 명확한 HOLD
- 거래 발행사 기준 적용
- 고객 산업·업무·연구방향 직접 매칭
- 최근성 고려
- 발행사 분산
- 제목 = 실제 링크 제목
- 링크 정상
- 중복 자료 없음
- 출력 형식 세로 배치

## 14. 단일 대화창 운영 원칙
- 앞으로 분야별 고객 안내 규칙은 이 통합 규칙을 공통마스터로 사용한다.
- 방산/반도체/조선/탄소/인공지능/로봇 등 분야 차이는 고객 데이터와 분야 키워드에서만 처리하고, 공통 작업 절차는 나누지 않는다.
- 과거 분야별 대화기록 데이터는 별도 보관하며 이 규칙 문서에 중복 저장하지 않는다.
- 새 분야별 규칙이 생기면 별도 대화창 규칙 문서를 계속 늘리지 말고 이 공통 규칙에 충돌 없이 흡수한다.
- 분야 특화 예외가 꼭 필요하면 공통 규칙 아래 `분야 예외`로 최소 추가한다.
