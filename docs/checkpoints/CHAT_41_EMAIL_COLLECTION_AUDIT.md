## 확정된 충돌 판정
1. 과거 `7개 필수값 전부/전화 필수` vs 최신 `이름+이메일+직책 + 부서/담당업무 중 1개, 전화 선택` → 최신 직접지시 유지.
2. 과거 대학/교수 포함 또는 기관군 강제 포함 vs 최신 대학 기본 제외 → 최신 직접지시 유지.
3. 과거 신규 인력만 출력 vs 최신 기존 고객 우선 재활용 → 기존 고객 우선 유지.
4. 과거 상세 12~18열 내부 발송관리표 vs 최신 사용자 고정 18열 → 사용자 고정 본표 유지, 발송리스크·도메인·재배치 정보는 내부 관리.
5. 과거 직책 미확인 인력 본표 허용 기록 vs 최신 직책 필수 → 최신 직책 필수 유지.
6. 과거 `고정 링크/만료 링크/재검색 경로` 별도 열 vs 최신 18열 고정 → 별도 열 복원 없이 공식 검증출처의 재현성 보조정보로 통합.
7. 과거 `100명마다 사용자 확인 후 계속` vs 최신 작업중단 최소화 → 사용자 재확인 요구 없이 목표/공식자료 한계까지 진행.
8. 인공지능 v4.0의 `대학 포함 기관군 교차 강제` vs 최신 대학 기본 제외 → 대학 강제 규칙 폐기, 허용된 기관군 안에서 분산만 유지.
